# 🧠 Умный Калькулятор | Σuler.SC

![Умный Калькулятор](HEADLINE.png)

**Мгновенное решение математических задач — без интернета!**

## 🎯 Какую проблему решает приложение

Тратите много времени на рутинные расчёты, построение графиков и проверку решений? Хотите не просто получить ответ, а **понять, как он получен**?

**Умный Калькулятор** помогает глубоко разбираться в математике:

* Моментально решает уравнения, неравенства и системы
* Строит красивые интерактивные графики с закрашиванием областей
* Даёт полный анализ функций (производные, экстремумы, интегралы и др.)
* Распознаёт задачи **прямо с фото** и предлагает решение
* Предоставляет **подробное объяснение решения** шаг за шагом с помощью локального ИИ

Идеально для школьников, студентов и всех, кто изучает математику самостоятельно.  
Экономьте время на рутине и сосредоточьтесь на понимании материала.

Всё работает **полностью оффлайн** после первой настройки (Ollama + модель скачивается один раз).

---

## ✨ Возможности

* **Классический калькулятор** с поддержкой `sin/cos/tan/ctg, √, ^, !, |x|, i, ln/log/lg, π, e, ∫, lim`
* **Решение уравнений и неравенств** → `x ∈ [-1; 3] ∪ (5; +∞)`
* **Системы уравнений** (до 4 штук)
* **Интерактивные графики** с зумом, перемещением и сохранением изображения
* **Анализ функции** (производная, интеграл, экстремумы, поведение функции и др.)
* **Решение по фото (Pix2Text)** — автоматически выбирает SymPy или ИИ для сложных задач
* **ИИ-решение** с подробными объяснениями шаг за шагом
* **Широкий выбор моделей** — используйте любую популярную локальную модель с настройкой объёма ОЗУ

## 🚀 Как начать работу

1. Скачайте [Σuler.SC_Setup.exe](Setup)
2. Запустите `Σuler.SC_Setup.exe` — он автоматически установит все необходимые библиотеки, PyInstaller и соберёт приложение
3. Запустите `Σuler.SC.exe`

**При первом запуске программа сама:**

* Установит Ollama (если его нет)
* Скачает выбранную модель ИИ
* Выберет папку для config

Готово за 2–10 минут!

---

## ⚙️ Настройка (config.txt)

```ini
[AI]
model = qwen2.5:7b
temperature = 0.3

[GRAPH]
x_min = -50
x_max = 50
y_min = -50
y_max = 50
points = 1500

[PATHS]
ollama_models = C:\your_path\.ollama\models
matplotlib_config = C:\your_path\.matplotlib
```

## ❗ Важно
Если при установке модели возникает ошибка с кодом 1, перепроверьте путь установки. Он должен совпадать с тем, что используется в Ollama.
Для этого:

Откройте приложение Ollama
Зайдите в настройки и выберите Reset to defaults
Если не помогло — укажите путь вручную:
`C:\your_path\.ollama\models`


## 🤖 Как работает ИИ

Фото → Pix2Text (распознаёт LaTeX-формулы)
Простые задачи → сразу SymPy
Сложные задачи → Ollama (любая доступная локальная модель)
Автоустановка Ollama + модель из конфига
Подробное пошаговое объяснение решения


## 📡 Стек технологий

GUI: Tkinter
Математика: SymPy 1.13
Графика: Matplotlib
OCR: Pix2Text
ИИ: Ollama
Python 3.12


## 📥 Источники

SymPy — все точные вычисления
Pix2Text — распознавание математических выражений с фото
Ollama — полностью локальный ИИ без интернета после установки
