# 🧠 Умный Калькулятор ЕГЭ | Профильная математика

![Умный Калькулятор](icon.png)

**Мгновенное решение задач ЕГЭ — без интернета!**
## 🎯 Какую проблему решает приложение

Готовитесь к ЕГЭ по профильной математике и тратите часы на монотонные расчёты, построение графиков и проверку ответов?

**Умный Калькулятор** решает эту проблему полностью:

* Моментально решает уравнения, неравенства и системы
* Строит графики с закрашиванием областей
* Даёт полный анализ функций
* Распознаёт и решает задачи **прямо с фото**
* Предоставляет подробное решение «по ФИПИ» с помощью локального ИИ

Идеально для самостоятельной подготовки: проверяйте себя, разбирайтесь в теме глубже и экономьте время.

Всё работает **полностью оффлайн** после первой настройки (Ollama + модель скачивается один раз).

---

## ✨ Возможности

* **Классический калькулятор** с поддержкой `sin/cos/tan/ctg, √, ^, !, |x|, i, ln/log/lg, π, e, ∫, lim`
* **Решение уравнений и неравенств** → `x ∈ [-1; 3] ∪ (5; +∞)`
* **Системы уравнений** (до 4 штук)
* **Интерактивные графики** с зумом, перемещением и сохранением
* **Анализ функции** (производная, интеграл, экстремумы)
* **Решение по фото (Pix2Text)** — автоматически выбирает SymPy или ИИ для сложных задач ЕГЭ
* **ИИ-решение** по шаблону ФИПИ (Что дано → Чертеж → Решение → Ответ)
* **Широкий выбор доступных моделей** Доступ к большому количеству самых популярных локальных моделей с возможностью выбора количества затрачиваемой ОЗУ

## 🚀 Как начать работу

1. Скачайте **installer.exe** из [dist](dist)
2. Запустите `installer.exe` — он автоматически установит все библиотеки, PyInstaller и соберёт приложение
3. Запустите `SmartCalculator.exe`

**При первом запуске программа сама:**

* Установит Ollama (если его нет)
* Скачает выбранную модель ИИ

Готово за 2–10 минут!

---

## ⚙️ Настройка (config.txt)

```ini
[AI]
model = qwen2.5:7b
temperature = 0.3

[GRAPH]
x_min = -50
x_max = 50
y_min = -50
y_max = 50
points = 1500

[PATHS]
ollama_models = C:\Путь к папке\.ollama\models
matplotlib_config = C:\Путь к папке\.matplotlib
```

## ❗ Важно

Если при установке модели возникает ошибка с кодом `1` то перепроверьте путь установки. Он должен совпадать с тем что находится в Ollama.

  **Для этого:**
* Откроёте приложение `Ollama`
* Зайдите в настройки и выберите `Reset to defaults`
* Всё! проблема решена
* Если не помогло то выберите путь вручную:
    `C:\Путь к папке\.ollama\models`

## 🤖 Как работает ИИ

* Фото → Pix2Text (распознаёт LaTeX-формулы)
* Простые задачи → сразу SymPy
* Сложные задачи ЕГЭ → Ollama (любая доступная модель)
* Автоустановка Ollama + модель из конфига под любые задачи
* Подробное решение по ФИПИ:
  **«Что дано → Чертеж → Решение → Ответ»**

## 📡 Стек технологий

* **GUI:** Tkinter + эргономичный дизайн
* **Математика:** SymPy 1.13
* **Графика:** Matplotlib + интерактивная панель
* **OCR:** Pix2Text (LaTeX-распознавание)
* **ИИ:** Ollama (любая локальная модель)
* **Язык:** Python 3.12
